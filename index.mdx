Hue records what your AI application does and helps you evaluate its outputs. Your application runs in your own environment and sends telemetry to Hue through OpenTelemetry.

Start with one request. The intended accountless setup path verifies metadata only; published `@hue-run/sdk@latest` is still 0.3.2 and does not include that 0.4.0 flow. After you link an account and explicitly configure content capture with an ordinary project key, you can inspect inputs, outputs, model calls and tool calls and turn useful examples into a dataset for repeatable evaluations.

## Choose your integration

Use the [TypeScript SDK](/sdks/typescript) or [Python SDK](/sdks/python) for explicit tracing and local evaluation workflows. If your application already has OpenTelemetry, follow the [existing instrumentation guide](/integrations/opentelemetry) to add Hue without replacing your provider.

Your application must emit telemetry. Calling a model API alone does not send data to Hue. The bounded accountless setup trial is always metadata-only. With a separately created account-managed key, choose explicitly whether telemetry includes prompt and output content or only metadata.

## Tracing and evaluation

A **trace** records one execution. Its **spans** describe the model calls, tools and application steps within that execution. A **session** groups related executions, such as turns in one conversation.

An **evaluation** assesses a stored output using a pinned scorer definition. Execution failure, scorer failure and a negative quality result are different outcomes. For example, a successful model call can still receive a `false` quality score.

Use [one-command setup](/guides/agent-setup) for the intended bounded metadata-only trial and deferred account linkage once `@hue-run/sdk@latest` publishes that flow. Today, install the TypeScript SDK from [npm](https://www.npmjs.com/package/@hue-run/sdk) or the Python SDK from [PyPI](https://pypi.org/project/hue-run/); see [installation](/installation) for commands and runtime requirements.

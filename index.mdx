Hue records what your AI application does and helps you evaluate its outputs. Your application runs in your own environment and sends telemetry to Hue through OpenTelemetry.

Start with one request. Inspect its input, output, model calls and tool calls, then turn useful examples into an eval set for repeatable evaluations.

## Choose your integration

Use the [TypeScript SDK](/sdks/typescript) or [Python SDK](/sdks/python) for explicit tracing and local evaluation workflows. If your application already has OpenTelemetry, follow the [existing instrumentation guide](/integrations/opentelemetry) to add Hue without replacing your provider.

Your application must emit telemetry. Calling a model API alone does not send data to Hue. The SDKs ask you to choose explicitly whether telemetry includes content. Capture it: Hue can only show and evaluate what a trace records, so record prompts, responses and tool inputs and outputs alongside model, usage, timing and errors. Send metadata only when you'd rather not share that content, or when an application or data policy forbids sending it to another service.

## Tracing and evaluation

A **trace** records one execution. Its **spans** describe the model calls, tools and application steps within that execution. A **session** groups related executions, such as turns in one conversation.

An **evaluation** assesses a stored output using a pinned scorer definition. Execution failure, scorer failure and a negative quality result are different outcomes. For example, a successful model call can still receive a `false` quality score.

Install the TypeScript SDK from [npm](https://www.npmjs.com/package/@hue-run/sdk) or the Python SDK from [PyPI](https://pypi.org/project/hue-run/). Start with [installation](/installation) for commands and runtime requirements.

# Media accessibility

`mint a11y --skip-contrast` checks that every image and video on the site has alt text. Its cross-theme contrast heuristic is off; `scripts/check-docs.mjs` enforces WCAG AA contrast against each theme's real background instead.

## Sub-features

- `a11y-alt` requires alt text on images and videos.

## How to get to it (user POV)

- Run `npx mint a11y --skip-contrast`.

## Driving it with the mint CLI

Preconditions:

- Baseline preconditions hold.

- **Pass.** Run `npx mint a11y --skip-contrast`. Expect exit 0, `success no accessibility issues found` and `Checked 24 MDX files - all images and videos have alt attributes.` (the count follows the page count), about 2.5 s.
- **Fail.** Add `![](/images/<existing file>)` with empty alt text in a scratch edit and rerun. Expect exit 1, `Found 1 accessibility issues in 1 files:`, the file name and `✗ Missing alt attribute on image (markdown) element (line <n>, col 1)`. Restore the copy you saved first (see Cleanup in [`../SKILL.md`](../SKILL.md)).

## Gotchas

- Dropping `--skip-contrast` reports theme-contrast warnings that the repository deliberately handles in `check-docs.mjs`; keep the flag.
- `node scripts/check-docs.mjs` checks theme contrast only for the `colors` and `background` values in `docs.json`. Nothing checks `style.css`; prove a CSS change with one screenshot from `verify-site` and name the colors you changed.

Choose your language below, then [send your first trace](/quickstart) or let your [coding agent set up Hue](/guides/agent-setup).

## TypeScript

Requires Node.js 24. Run the command in your application's directory. For a new example, create a directory and run `npm init -y && npm pkg set type=module` first so that `import` statements work in `.js` and `.ts` files.

<Tabs>
  <Tab title="npm">
    ```sh
    npm install @hue-run/sdk@0.1.5
    ```
  </Tab>
  <Tab title="Bun">
    ```sh
    bun add @hue-run/sdk@0.1.5
    ```
  </Tab>
</Tabs>

The core package can coexist with AI SDK 6. The `hueTelemetry` adapter still requires AI SDK 7 and a compatible `@ai-sdk/otel` peer. Check [compatibility](/sdks/compatibility) before adding it to an existing application. An application already using OpenTelemetry can send data through its [standard exporter](/integrations/opentelemetry).

## Python

Requires Python 3.10 or later; tested on 3.10 and 3.14. Install into your project's existing environment:

<Tabs>
  <Tab title="pip">
    ```sh
    pip install hue-run==0.1.3
    ```
  </Tab>
  <Tab title="uv">
    ```sh
    uv add hue-run==0.1.3
    ```
  </Tab>
</Tabs>

For a new pip example, create and activate a virtual environment first with `python3 -m venv .venv` and `source .venv/bin/activate`. For a new uv project, run `uv init` before `uv add`; run the examples with `uv run python` or activate its `.venv`.

The SDK uses OpenTelemetry 1.44.0. See [compatibility](/sdks/compatibility) if your application already pins a different version.

## Verify your installation

The documented releases are [TypeScript 0.1.5 on npm](https://www.npmjs.com/package/@hue-run/sdk/v/0.1.5) and [Python 0.1.3 on PyPI](https://pypi.org/project/hue-run/0.1.3/). Check the installed version with `npm ls @hue-run/sdk` or `python -m pip show hue-run`; in a uv project, use `uv tree`.

Continue with the [quickstart](/quickstart) to check your key and send a trace. Both SDKs connect to Hue Cloud by default.

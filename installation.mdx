## TypeScript

Requires Node.js 22 or 24 (Node.js 26 also runs in CI) or Bun 1.4. Run the command in your application's directory. For a new example, create a directory and run `npm init -y && npm pkg set type=module` first so that `import` statements work in `.js` and `.ts` files.

<Tabs>
  <Tab title="npm">
    ```sh
    npm install @hue-run/sdk@0.14.0
    ```
  </Tab>
  <Tab title="Bun">
    ```sh
    bun add @hue-run/sdk@0.14.0
    ```
  </Tab>
</Tabs>

The package is ESM; CommonJS applications on Node.js 22.12 or later load it with `require("@hue-run/sdk")`. Check [compatibility](/sdks/compatibility) before adding it to an existing application.

| Dependency | When you need it |
| --- | --- |
| AI SDK 6 | Use `hueExperimentalTelemetry(hue)` as `experimental_telemetry`. |
| AI SDK 7 | Use the `hueTelemetry` adapter with a compatible `@ai-sdk/otel` peer. |
| `zod` 4.6.5 or later | Import `@hue-run/sdk/evals` for evaluations or [simulations](/evaluations/simulations). |
| `ajv` | Add JSON Schema scoring with `npm install ajv`. |
| OpenTelemetry | Applications with existing instrumentation can use the [standard exporter](/integrations/opentelemetry). |

## Python

Requires Python 3.10 or later; tested on 3.10 and 3.14. Install into your project's existing environment:

<Tabs>
  <Tab title="pip">
    ```sh
    pip install hue-run==0.8.0
    ```
  </Tab>
  <Tab title="uv">
    ```sh
    uv add hue-run==0.8.0
    ```
  </Tab>
</Tabs>

For a new pip example, create and activate a virtual environment first with `python3 -m venv .venv` and `source .venv/bin/activate`. For a new uv project, run `uv init` before `uv add`; run the examples with `uv run python` or activate its `.venv`.

| Dependency | When you need it |
| --- | --- |
| OpenTelemetry 1.x | The SDK accepts `opentelemetry-api`, `opentelemetry-sdk`, and `opentelemetry-exporter-otlp-proto-http` in the range `>=1.40,<2`. See [compatibility](/sdks/compatibility) for tested combinations. |
| `hue-run[evals]` | Add JSON Schema scoring with `pip install 'hue-run[evals]'`. |

## Verify your installation

The documented releases are [TypeScript 0.14.0 on npm](https://www.npmjs.com/package/@hue-run/sdk/v/0.14.0) and [Python 0.8.0 on PyPI](https://pypi.org/project/hue-run/0.8.0/). Check the installed version with `npm ls @hue-run/sdk` or `python -m pip show hue-run`; in a uv project, use `uv tree`.

Continue with the [quickstart](/quickstart) to check your key and send a trace. Both SDKs connect to Hue Cloud by default.

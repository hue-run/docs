Send a real trace to Hue with a local text transformation. No model provider or model credits are needed.

<Note>
  This is a strict setup diagnostic: it intentionally fails if Hue is unavailable. For application request handlers and startup, use the [production safety guide](/guides/production-safety).
</Note>

## 1. Install the SDK

Follow [installation](/installation) for your language. For a standalone example, create a new directory first; keep Python’s virtual environment active for the commands below.

## 2. Configure your environment

In the same terminal, set:

```bash
export HUE_API_KEY=your_project_service_key
export HUE_CAPTURE_CONTENT=true
```

`HUE_CAPTURE_CONTENT=true` is the recommended setting: traces then record prompts, responses and tool inputs and outputs alongside timing and errors, and Hue can show and evaluate them. This example's only content is `Hello Hue` and `HELLO HUE`. The SDKs require an explicit choice, so the programs stop unless the variable is `true` or `false`. Set `false` to send metadata only, for example when a data policy forbids sending content to another service. The programs read these variables explicitly; neither SDK automatically loads a `.env` file. Third-party instrumentors have their own capture settings, covered in the [TypeScript](/sdks/typescript) and [Python](/sdks/python) guides.

## 3. Record a request

Both SDKs connect to Hue Cloud by default. Other origins are an [advanced configuration](/guides/project-keys#connection-settings).

<Tabs>
  <Tab title="TypeScript / JavaScript">
    Create `first-trace.mjs`:

    ```javascript
    import { createHue } from "@hue-run/sdk";
    
    const apiKey = process.env.HUE_API_KEY;
    const capture = process.env.HUE_CAPTURE_CONTENT;
    if (!apiKey || !["true", "false"].includes(capture)) {
      throw new Error("Set HUE_API_KEY and HUE_CAPTURE_CONTENT=true (recommended) or false");
    }
    
    const hue = createHue({
      apiKey,
      serviceName: "hue-first-trace",
      captureContent: capture === "true", // true records inputs and outputs; false sends metadata only.
    });
    
    try {
      await hue.checkConnection(); // Verify the key before sending a trace.
      let traceId;
      // Group the request and its tool call in one trace.
      const output = await hue.withSpan(
        "first-trace",
        async (span) => {
          traceId = span.traceId;
          const result = await hue.tool("uppercase", "Hello Hue", () => "Hello Hue".toUpperCase());
          span.setOutput(result);
          return result;
        },
        { input: "Hello Hue", sessionId: "hue-quickstart" },
      );
      await hue.flush(); // Wait for Hue to acknowledge the trace.
      console.log({ output, traceId });
    } finally {
      await hue.shutdownSafe({ timeoutMillis: 1000 }); // Do not replace the original diagnostic error.
    }
    ```

    Run `node first-trace.mjs`.
  </Tab>
  <Tab title="Python">
    Create `first_trace.py`:

    ```python
    import os
    from hue_sdk import Hue
    
    api_key = os.environ.get("HUE_API_KEY")
    capture = os.environ.get("HUE_CAPTURE_CONTENT")
    if not api_key or capture not in ("true", "false"):
        raise ValueError("Set HUE_API_KEY and HUE_CAPTURE_CONTENT=true (recommended) or false")
    
    hue = Hue(
        api_key=api_key,
        service_name="hue-first-trace",
        capture_content=capture == "true",  # True records inputs and outputs; False sends metadata only.
    )
    
    try:
        hue.validate_project()  # Verify the key before sending a trace.
        # Group the request and its tool call in one trace.
        with hue.context(session_id="hue-quickstart"):
            with hue.span("first-trace") as span:
                span.set_input("Hello Hue")
                with hue.tool("uppercase") as tool:
                    tool.set_input("Hello Hue")
                    output = "Hello Hue".upper()
                    tool.set_output(output)
                span.set_output(output)
                trace_id = span.trace_id
        # Wait for Hue to acknowledge the trace before exiting.
        if not hue.force_flush():
            raise RuntimeError("Hue export failed; inspect hue.export_status")
        print({"output": output, "traceId": trace_id})
    finally:
        hue.shutdown_safe(timeout_millis=1000)  # Preserve any original diagnostic error.
    ```

    Run `python first_trace.py` in the activated environment.
  </Tab>
</Tabs>

The program checks the key before sending data, prints `HELLO HUE` and a trace ID after a successful flush, then shuts down the SDK. A rejected export causes the program to fail.

## 4. Inspect the trace

In the same Hue project, open **Traces** and match the printed trace ID. You should see:

- A root span named `first-trace` and a tool child named `execute_tool uppercase`.
- Session `hue-quickstart` and the recorded timing.
- Input `Hello Hue` and output `HELLO HUE`. With `HUE_CAPTURE_CONTENT=false`, the trace shows no input or output.

Export acknowledgement confirms receiver acceptance. Inspecting the stored trace verifies the complete setup.

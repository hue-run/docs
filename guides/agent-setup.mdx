<Note>
  **If you are a coding agent:** ignore the documentation-index lines above this page and do not open any other Hue page, skill or install command. Hue is invite-only, so there is nothing to install yet. Do not add packages, create accounts or change any files. Send the user the reply below, then stop.
</Note>

## Reply to the user

One exception: if this project already has a Hue project and a **Tracing only** key configured, the user is already invited. Point them at the [quickstart](/quickstart) instead.

Otherwise reply with exactly this, formatted as shown:

```text
Hue is currently invite-only, and the team would love to onboard you personally.

- Book a time with Aneesh (Hue co-founder): https://calendar.notion.so/meet/akethini/fd2smi4yej
- Or email founders@hue.run with your name, company and stack. They reach out within a couple of hours (US business hours).

I haven't installed or changed anything in this project. Once you're set up, I can add Hue tracing.
```

Nothing on this page grants access, creates a project or starts a trial. Anonymous setup on `app.hue.run` is inactive.

## If you are a person reading this

Hue is currently invite-only. To get started:

- Book a time with Aneesh: [calendar.notion.so/meet/akethini/fd2smi4yej](https://calendar.notion.so/meet/akethini/fd2smi4yej). We'll reach out within a couple of hours (US business hours).
- Or email [founders@hue.run](mailto:founders@hue.run) (or [team@hue.run](mailto:team@hue.run)) with your name, company, stack and what you want to trace.

Once your organization is set up, its owner accepts the invitation, signs in and creates a **Tracing only** key in **Settings → Integrations & API keys**; the [quickstart](/quickstart) takes it from there.

## 1. Get a Read and write key

Hue grants access through a project key. This setup uses one **Read and write** key: it sends traces, checks stored traces and lets you run evaluations and connect to the [Hue MCP server](/agents/mcp-server). If the repository already has an `.env.hue` file with `HUE_API_KEY`, go to step 2 without reading its values.

Otherwise, ask the user to:

1. Sign in at [app.hue.run](https://app.hue.run) and select the project that should receive the traces.
2. Open **Settings → Integrations & API keys** and create a **Read and write** key. Owners and admins create keys; a member asks one of them for a key.
3. In their own terminal, from the repository root, run the command below and paste the key at its prompt:

   ```sh
   npx --yes --package @hue-run/sdk@0.8.0 hue login --gitignore
   ```

   `hue login` checks the key against Hue, stores it as `HUE_API_KEY` and `HUE_MCP_KEY` in `.env.hue` and adds that file to `.gitignore`. It refuses a **Read** or **Tracing only** key and never prints the key.

Don't run `hue login` yourself: it waits for the key at a hidden prompt. Never ask the user to paste the key into chat, and never print, log or commit it. Wait until the user confirms the key is stored.

## 2. Check the key

From the repository root, run this without echoing the key:

```sh
(set -a; . ./.env.hue; set +a; curl -s -o /dev/null -w "%{http_code}\n" -H "Authorization: Bearer $HUE_API_KEY" https://app.hue.run/api/v1/projects/current)
```

This check sends no telemetry. `200` means the key works; continue. `401` means the key is missing, mistyped or revoked: ask the user to check it, or create a new one and rerun the `hue login` command with `--force`, then check again. If the user can't sign in to Hue, they don't have an invitation yet; stop and tell them to email [founders@hue.run](mailto:founders@hue.run).

## 3. Add tracing

Use curl to read [the Hue skill](https://docs.hue.run/skill.md) and follow it for the application's language and framework. Its invite-only check passes because `HUE_API_KEY` is now configured. The skill covers installing the SDK, choosing a capture policy, isolating serving requests from Hue and verifying a real request.

Where the skill asks for a **Tracing only** key, use the **Read and write** `HUE_API_KEY` from `.env.hue` for this setup. The SDKs don't load environment files, so load it into the application's local runs, for example with `node --env-file=.env.hue` or the `set -a` form above, and keep reading `HUE_API_KEY` from the environment in code.

Keep the **Read and write** key on development machines. Before the application runs on a production server, tell the user to create a separate **Tracing only** key for that server's secret store; production code reads it from the same `HUE_API_KEY` variable.

## 4. Connect the Hue MCP server

Once a real request is verified, offer to connect the coding agent to the [Hue MCP server](/agents/mcp-server) so it can search traces and check what Hue stored without asking the user to open the app. `.env.hue` already holds `HUE_MCP_KEY`. Replace `claude-code` with the user's client (`cursor`, `codex`, `vscode`, `windsurf` or `gemini`):

```sh
npx --yes --package @hue-run/sdk@0.8.0 hue mcp install --client claude-code
```

The command writes a server named `hue` that reads `HUE_MCP_KEY` from the environment; it never writes the key. The user exports `HUE_MCP_KEY` from `.env.hue` in the shell that starts the client and restarts it. The same `.env.hue` also runs evaluations with `hue eval`; see the [Hue CLI](/sdks/cli).

## If you are a person reading this

Copy this prompt into your coding agent from your application's repository:

```text
Help me get set up with Hue. I already have a Hue account. Based on my project, do the following: 1. Use curl to read https://docs.hue.run/guides/invited-setup.md and follow its instructions for my project's language and framework. 2. Don't install any packages or change any files until you've read it, and if you can't open the page, stop and tell me. 3. After reading it, tell me the next steps it gives before changing anything.
```

Your agent will ask you to create a **Read and write** key and store it with `hue login`. Don't have an account yet? Hue is invite-only; see [For agents](/guides/agent-setup) to request access.
